# Dataset

The project uses three input CSV files:

- `dataset_1.csv` — 1,000 records
- `dataset_2.csv` — 270 records
- `dataset_3.csv` — 303 records

The datasets are merged and standardized before model training.

The original datasets are not included in this repository. Please obtain them from their original sources and place them in this directory using the filenames above.

Do not upload private, restricted, or copyrighted datasets without permission.
